# Privacy Policy

This Privacy Policy governs the use of this private desktop application (the "Application"). The Application is a personal, private utility designed solely for the developer's individual use to interact with the Gmail and Google Calendar APIs.

## Data Collection and Use
* **No Data Collection:** The Application does not collect, harvest, transmit, track, or monitor any personal data, usage statistics, or behavioral metrics.
* **No Storage:** Any data retrieved from third-party APIs (such as Gmail or Google Calendar) is processed locally on your machine in real-time. The Application does not save, cache, or store your messages, credentials, or personal information on any external servers or local databases, except for the local session token (`token.json`) required to maintain the API connection.
* **No Third-Party Sharing:** Since no data is collected or stored, no data is ever sold, leased, or shared with third parties. 
* **Safety Guarantee:** For absolute clarity, the Application does not engage in any malicious activities, data exploitation, or the consumption of anyone's younglings.

## Changes to This Policy
Because this is a private application for personal use, this policy is stable and unlikely to change. However, any structural updates to the application's local workflow will be reflected in this document.
